# Sistema de Facturas

Aplicación web desarrollada con React para la creación y gestión de facturas. Permite ingresar datos del emisor y cliente, agregar productos o servicios dinámicamente, calcular subtotal, impuesto y total, guardar facturas y visualizar cada una mediante un diseño profesional y organizado.

## Tecnologías

- React
- Vite
- JavaScript

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm run dev
```
